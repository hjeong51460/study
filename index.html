공부 기간과 과목을 먼저 설정하세요
오른쪽 위 D-day는 종료일까지 남은 날이에요. 진도 계산은 시작일부터 종료일 사이의 공부 요일(월~금)만 세요. 시작 전에 이미 읽은 분량은 아래 "과목별 페이지 설정"의 기존에 넣어두세요.

과목별 페이지 설정
"격주 교대"를 켜면 시작일이 속한 주(시작일이 일요일이면 그다음 주)를 첫 주로 해서 첫 주 요일 → 다음 주 요일 순서로 번갈아요. "목표 회독"은 과목마다 따로 정해요. "현재 회독 · 기존 페이지"는 앱을 쓰기 전에 이미 읽은 위치예요 (예: 2회독 50p). 특정 날짜의 기록으로 남기지 않고 별도로 반영되기 때문에, 하루 만에 다 읽은 것처럼 기록에 남지 않아요. 값을 입력한 뒤 위 "적용하기"를 눌러야 반영돼요.
